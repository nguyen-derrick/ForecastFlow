# ForecastFlow

ForecastFlow is a small revenue forecasting tool. It models monthly revenue using past data and marketing spend. You can adjust growth and spend sensitivity. The forecast updates in real time and shows both charts and tables.

## Features
- Enter past monthly revenue.
- Enter marketing spend.
- Adjust growth rate.
- Adjust spend sensitivity.
- View updated forecast in real time.
- See charts and data tables.

## How It Works
The tool takes your historical data, applies a base growth rate, and then modifies the forecast based on the spend input. The chart updates when you change any value.

## Tech Stack

- React
